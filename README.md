# Homebrew tap for Anvil

[Anvil](https://anvil.tr) is a native development environment for macOS.

```sh
brew install --cask n1crack/anvil/anvil   # the app, with the anvil CLI
brew install n1crack/anvil/anvil          # only the CLI
```

Install one of them: both put `anvil` on PATH. The files here are updated by
the [anvil](https://github.com/n1crack/anvil) release workflow.
